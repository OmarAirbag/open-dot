# Regole specifiche di questo repo

Questa cartella contiene **solo** le regole proprie di questo progetto (convenzioni
Airbag v0.4.0, §2). Le convenzioni condivise — costituzione e regole per piattaforma —
**non si copiano qui**: arrivano dal plugin `airbag-dev` del marketplace interno
(`/plugin install airbag-dev@airbag-plugins`), il cui master è
`orchestratore-progetti/rules/` (ADR 0002 dell'àncora).

- Un errore o una lacuna nelle regole condivise è una **PR sull'àncora**, mai una
  copia corretta in loco né un'eccezione silenziosa in questo repo.
- Le regole di questo repo vanno in file separati (`<tema>.md`), con la motivazione
  dell'eccezione o dell'aggiunta rispetto alle convenzioni condivise.
